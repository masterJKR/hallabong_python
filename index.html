4교시 : 탐지 결과 이해하기

목표 : 단순 실행에서 끝내지 않고 confidence 값을 조절해본다.

기본 실행 코드 변경

from ultralytics import YOLO

model = YOLO("yolov8n.pt")

results = model(0, show=True, conf=0.5)

confidence 설명

conf=0.5는 확신도가 50% 이상인 객체만 표시한다는 의미다.

conf 값의미
0.25약하게 의심되는 객체도 표시
0.5어느 정도 확실한 객체만 표시
0.7매우 확실한 객체만 표시

비교 실습

results = model(0, show=True, conf=0.25)
results = model(0, show=True, conf=0.7)

실습 질문

  1. conf 값을 낮추면 탐지 개수가 어떻게 변하나요?
  2. conf 값을 높이면 탐지 개수가 어떻게 변하나요?
정답 방향 : conf를 낮추면 많이 잡지만 오탐이 늘어난다. conf를 높이면 적게 잡지만 더 확실한 것만 잡는다.

5교시 : 특정 객체만 탐지하기

목표 : 사람만, 컵만, 휴대폰만 탐지하는 방법을 이해한다.

from ultralytics import YOLO

model = YOLO("yolov8n.pt")

print(model.names)

출력 예시

{
    0: 'person',
    1: 'bicycle',
    2: 'car',
    ...
    39: 'bottle',
    41: 'cup',
    63: 'laptop',
    67: 'cell phone'
}

사람만 탐지하기

from ultralytics import YOLO

model = YOLO("yolov8n.pt")

results = model(
    0,
    show=True,
    classes=[0],
    conf=0.5
)

컵만 탐지하기
